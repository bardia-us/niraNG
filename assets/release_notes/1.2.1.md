## English

- Home glass coordinates now follow vertical scrolling and connection-card size changes in the current paint. Restart Service expands/collapses its own layout over a gentler 360/300ms motion, so following content and Subscription usage move with it instead of jumping.
- Repeated heavy commands are single-flight with a minimum 500ms post-completion cooldown, using a monotonic clock and no background timers. Connect, Disconnect and Restart also share a 500ms start interval, preventing rapid alternating taps from bypassing separate command locks. No taps are queued; the first accepted tap stays immediate, and Disconnect can cancel a slow Connect after the interval.
- Server remarks use slightly smaller, tighter typography and less unused horizontal spacing. A continuous rim-free frosted navigation surface extends behind Android's transparent system buttons, without a separate bottom strip or optical edge.

- The fixed Servers header blocks touches on covered rows. Connection-card height changes animate with the panel instead of jumping. App and registration screens use a fixed standard font scale.
- CDN/TLS fingerprint, ALPN and cipher settings offer supported selections; imported untouched values are preserved, and REALITY excludes `unsafe`. Profile feedback uses themed transient messages and the Selected badge is more compact.
- Scrolling cancels row press compression after touch slop. Glass transform tracking avoids requesting a duplicate repaint after an already synchronized paint. Performance mode uses upstream's lighter 2D glass only for repeated three-dot lenses; open menus and normal-mode optics stay unchanged.

- Server-row glass now refreshes optical coordinates during vertical scrolling and row press/release, avoiding a one-frame mismatch between the circular lens and its three-dot icon. Header overlap exclusion and the stationary row-control geometry are retained.

- Settings dialogs now prime their glass before a short fade/scale entrance; reduced-motion preferences remain respected. Manual update checks use a small themed confirmation instead of the plain snackbar.
- Dragging an elastic glass control no longer scrolls its parent list or pager. Page swipes settle with a shorter critically damped spring, without a forced last-pixel jump.
- Removed nonuniform whole-scroll stretching and the offset shadow from row action lenses; their square bounds and optical rim remain. Glass bodies apply subtle 3.5% backdrop magnification without scaling foreground labels/icons.

- Light-mode Liquid Glass panels, menus and dialogs now use a continuous native Gaussian blur instead of preserving sharp backdrop details through frost/ghost rows. Small-control optics, dark tint and curved refraction remain unchanged.
- Server-row three-dot controls stay circular without their own stretch/press-scale animation. The header control, elastic Connect button, row feedback and spring-opening menus retain their animations.
- Fit the three-dot lens to the compact server row on both axes: a 40-point height limit no longer flattens a 44-point-wide circle into an oval.
- Exclude only header-covered portions of scrolling server-row action controls from painting, avoiding a lens behind the fixed Servers lens. Outside the rounded header, controls retain the same glass; popup overlays and server text are not masked.
- Page transitions finish their animation naturally instead of jumping through the last two pixels. Destination input still unlocks at 80% visibility.
- Glass repaint traversal skips invisible retained pages. Glass menu triggers can participate in shared backdrop filtering without an enclosing opacity layer; their fade, keyboard focus and accessibility still follow menu visibility.
- Version 1.2.1, base build 23. Existing app identity, signing key, configurations and settings are retained. Backend/PHP, Windows and VPN-core selection are not changed.
- Four signed APKs are provided: ARM64 (`arm64-v8a`), ARM32 (`armeabi-v7a`), x86-64 (`x86_64`) and a universal APK containing all three. Choose universal if unsure; it is larger. Android 7.0/API 24+ and a supported ABI are required.
- All four installation version codes are `4023`, above release 1.2.0 (`4022`) and historical 1.1.9 ABI codes. Update in place with the matching architecture or universal; no uninstall, clone or intermediate test builds are needed. Stored settings, installation identity, subscription cache and existing profile values are reused. Upgrade packaging/data paths were reviewed; fresh physical-device upgrade from each historical version was not performed.

Earlier automated regression tests cover material settings, controls and menu behavior. The final navigation/alternating-tap follow-up was built and analyzed, without rerunning the test suite at the publisher's request. Appearance and frame rate still depend on the device; no universal FPS guarantee is claimed.

### Installation prompts
- Google Play Protect can ask to scan an unfamiliar APK installed outside Google Play; this prompt alone does not mean malware was detected. APK signing does not replace Google's scanning/reputation checks. Do not disable protection to silence it. [Official Google guidance](https://developers.google.com/android/play-protect/warning-dev-guidance).
- VPN consent is Android's authorization to create the VPN tunnel. Notification permission supports service status; permission to install unknown apps is used only for the user-triggered in-app APK updater. Scan prompts and these permissions are different system mechanisms.

## فارسی

- مختصات گلس هوم با اسکرول عمودی و تغییر اندازهٔ کارت اتصال در همان نقاشی تازه می‌شود. Restart Service با حرکت نرم‌تر ۳۶۰/۳۰۰ میلی‌ثانیه باز و بسته می‌شود؛ محتوای زیرش و کارت مصرف ساب همراهش جابه‌جا می‌شوند، نه ناگهانی.
- عملیات سنگین تکراری هم‌زمان اجرا نمی‌شوند و بعد از پایان هر درخواست حداقل ۵۰۰ میلی‌ثانیه فاصله دارند؛ بدون تایمر پس‌زمینه و با ساعت یکنواخت. شروع Connect، Disconnect و Restart هم فاصلهٔ مشترک ۵۰۰ میلی‌ثانیه‌ای دارد تا لمس رفت‌وبرگشتی قفل جداگانه را دور نزند. لمس اضافه صف نمی‌شود؛ اولین لمس پذیرفته‌شده فوری است و بعد از این فاصله همچنان می‌توان اتصال طولانی را لغو کرد.
- فونت و فاصلهٔ افقی نام کانفیگ‌ها کمی جمع‌وجورتر است تا اسم بیشتری جا شود. سطح بلوری بدون لبهٔ پایین، یک‌تکه تا پشت دکمه‌های شفاف خود اندروید ادامه دارد؛ نوار جدا با رنگ متفاوت ندارد.

- هدر ثابت سرورها، لمس ردیف‌های زیرش را مسدود می‌کند. تغییر ارتفاع کارت اتصال همراه خود پنل نرم می‌شود. فونت اپ و صفحه‌های ثبت دستگاه اندازهٔ استاندارد ثابت دارند.
- تنظیمات CDN/TLS برای فینگرپرینت، ALPN و Cipher گزینهٔ انتخابی دارند؛ مقادیر واردشدهٔ دست‌نخورده حفظ می‌شوند و REALITY گزینهٔ `unsafe` ندارد. پیام ذخیره هماهنگ با تم است و نشان Selected جمع‌وجورتر شده.
- شروع اسکرول، فشردگی ردیف را لغو می‌کند. بعد از نقاشی هماهنگ گلس، درخواست بازنقاشی اضافه حذف شده است. Performance فقط برای سه‌نقطه‌های تکراری از گلس دوبعدی سبک‌ترِ پکیج استفاده می‌کند؛ منوی باز و گلس حالت عادی تغییر نکرده‌اند.

- مختصات اپتیکی گلس سه‌نقطه با اسکرول عمودی و فشردن/رهاکردن ردیف در همان فریم تازه می‌شود؛ بدنهٔ دایره و آیکن دیگر به‌خاطر عقب‌ماندن مختصات از هم جدا نمی‌شوند. استثنای گلس زیر هدر و شکل ثابت دکمه حفظ شده‌اند.

- دیالوگ‌های تنظیمات بعد از آماده‌شدن گلس، با محوشدن و بزرگ‌شدن کوتاه و نرم باز می‌شوند؛ کاهش حرکت همچنان رعایت می‌شود. نتیجهٔ بررسی دستی آپدیت با پیام کوچک هماهنگ با تم نمایش داده می‌شود.
- کشیدن کنترل گلس، لیست یا صفحهٔ پشتش را اسکرول نمی‌کند. رهاکردن صفحه با فنر کوتاه‌تر و بدون پرش دستیِ پیکسل آخر به مقصد می‌رسد.
- کشیدگی غیریکنواخت کل اسکرول و سایهٔ جابه‌جاشدهٔ سه‌نقطه حذف شد؛ اندازهٔ مربعی و لبهٔ اپتیکی حفظ شده‌اند. بزرگ‌نمایی ملایم ۳٫۵٪ فقط روی پس‌زمینهٔ گلس است، نه متن و آیکن روی آن.

- پنل‌ها، منوها و پیام‌های Liquid Glass در حالت روشن از بلور پیوستهٔ بومی استفاده می‌کنند؛ جزئیات پشت پنل دیگر از مسیر ردیف‌های واضحِ frost/ghost عبور نمی‌کنند. متریال دکمه‌های کوچک، رنگ دارک و شکست نور خمیده حفظ شده‌اند.
- دکمهٔ سه‌نقطهٔ کنار کانفیگ دایره می‌ماند و کش‌آمدن و تغییر اندازهٔ مستقل خودش حذف شده است. انیمیشن دکمهٔ بالای سرورها، کشسانی اتصال، بازخورد ردیف و بازشدن فنری منوها حفظ شده‌اند.
- گلس سه‌نقطه در هر دو جهت داخل ردیف فشرده جا می‌گیرد؛ محدودیت ارتفاع ۴۰ دیگر دایره‌ای با عرض ۴۴ را تخت و بیضی نمی‌کند.
- فقط بخش دکمهٔ سه‌نقطه که زیر هدر ثابت سرورها می‌رود از نقاشی خارج می‌شود تا گلس روی گلس نیفتد. بیرون محدودهٔ گرد هدر، همان گلس باقی می‌ماند؛ منوی بازشده و متن سرور پوشانده نمی‌شوند.
- جابه‌جایی صفحه‌ها بدون پرش دستیِ دو پیکسل آخر، انیمیشن خود را کامل می‌کند. لمس صفحهٔ مقصد همچنان از ۸۰٪ نمایان‌شدن آزاد است.
- بازنقاشی گلس صفحات نگه‌داشته‌شدهٔ نامرئی حذف شده؛ دکمه‌های منو بدون لایهٔ opacity اضافی می‌توانند از بلور مشترک استفاده کنند. محوشدن دکمه، فوکوس کیبورد و دسترس‌پذیری همچنان با وضعیت منو هماهنگ‌اند.
- نسخهٔ 1.2.1، بیلد پایهٔ 23؛ هویت و امضای اپ، کانفیگ‌ها و تنظیمات حفظ می‌شوند. بک‌اند/PHP، ویندوز و انتخاب هستهٔ VPN تغییری نکرده‌اند.
- چهار APK امضاشده: ARM64 (`arm64-v8a`)، ARM32 (`armeabi-v7a`)، x86-64 (`x86_64`) و یونیورسال واقعی شامل هر سه معماری. اگر معماری را نمی‌دانی یونیورسال را انتخاب کن؛ حجم بیشتری دارد. اندروید ۷/API 24 به بالا و معماری پشتیبانی‌شده لازم است.
- شمارهٔ نصب هر چهار فایل `4023` است؛ بالاتر از 1.2.0 با بیلد `4022` و کدهای معماری قدیمی 1.1.9. با فایل مناسب گوشی یا یونیورسال روی اپ فعلی آپدیت کن؛ حذف برنامه، کلون یا نصب بیلدهای آزمایشی وسط راه لازم نیست. تنظیمات، شناسهٔ نصب، کش ساب و مقادیر قبلی پروفایل دوباره خوانده می‌شوند. بسته‌بندی و مسیر دادهٔ آپدیت بررسی شد؛ آپدیت واقعی روی گوشی از تک‌تک نسخه‌های قدیمی انجام نشده است.

تست‌های خودکار مراحل قبل متریال، دکمه‌ها و رفتار منو را پوشش می‌دهند. اصلاح نهایی نوار پایین و لمس‌های رفت‌وبرگشتی بیلد و تحلیل شد؛ طبق درخواست ناشر تست کامل دوباره اجرا نشد. ظاهر و فریم همچنان وابسته به دستگاه‌اند؛ تضمین FPS یکسان برای همهٔ گوشی‌ها داده نمی‌شود.

### پیام‌های نصب
- Google Play Protect ممکن است برای APK ناشناختهٔ خارج از پلی درخواست اسکن بدهد؛ این پیام به‌تنهایی به معنی شناسایی بدافزار نیست. امضای APK جای بررسی و اعتبارسنجی گوگل را نمی‌گیرد. برای حذف پیام، محافظت گوشی را خاموش نکن. [راهنمای رسمی گوگل](https://developers.google.com/android/play-protect/warning-dev-guidance).
- اجازهٔ VPN برای ساخت تونل است. مجوز اعلان برای وضعیت سرویس و اجازهٔ نصب برنامه‌های ناشناس برای آپدیت APK به درخواست خود کاربر استفاده می‌شود. درخواست اسکن و این مجوزها سازوکارهای متفاوت سیستم‌اند.
