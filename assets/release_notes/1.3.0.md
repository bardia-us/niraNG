## English

### niraNG 1.3.0 — mixed profiles and additional connection engines

- Subscriptions can deliver ordinary links, complete Xray/sing-box JSON and Aether presets together. Custom JSON keeps its original text and core-specific routing/DNS; required Android tunnel integration and safety checks still apply. JSON profiles have no ordinary TLS editor.
- Servers now has separate collapsible subscription and Aether groups. Local Aether presets can be created, renamed and edited in simple or advanced mode. Subscription presets remain source-owned and can be copied locally.
- Added pinned sing-box 1.14.4 and Aether 2.4.0 runtimes, including WireGuard-over-MASQUE and optional Psiphon chaining. Defaults include Aether with Psiphon and a plain Aether variant. Device identity is provisioned privately; endpoint testing/discovery has progress and cancellation. Network reachability and exit country are not guaranteed.
- Restored peer and hostname certificate verification in the bundled Aether HTTPS client; native binaries are checked against packaged hashes. Full configurations cannot expose unrestricted listeners, control APIs or local credential files.
- Fixed dark non-OLED background compositing when no content is behind a glass surface. Performance Mode update-download dialogs have a clearer border and distinct background.
- Important: disconnect before starting a complete Xray JSON profile; the current Xray binding has no non-mutating native JSON validator. Standalone delay measurements for complete JSON/Aether profiles are shown as “Not measured.” Custom Xray traffic accounting remains partial. Existing ordinary URI behavior is retained.

Version **1.3.0**, base build **55**, Android version code **4055**. Aether requires Android 10 or later. Install over the existing signed app; do not uninstall or clear data. Server/my-sub changes require their own deployment and are not installed by this APK.

## فارسی

### niraNG 1.3.0 — پروفایل‌های ترکیبی و هسته‌های اتصال بیشتر

- اشتراک می‌تواند لینک معمولی، JSON کامل Xray یا sing-box و پروفایل اتر را کنار هم داشته باشد. متن اصلی JSON و DNS و مسیریابی آن حفظ می‌شود؛ اتصال ضروری به تونل اندروید و کنترل‌های ایمنی همچنان اعمال می‌شوند. JSON ویرایشگر معمولی TLS ندارد.
- سرورها به دو بخش کشویی اشتراک و اتر تقسیم شدند. ساخت، تغییر نام و ویرایش ساده یا پیشرفتهٔ اتر شخصی اضافه شد. پروفایل اترِ اشتراک از منبع مدیریت می‌شود و می‌توان از آن نسخهٔ شخصی ساخت.
- هسته‌های sing-box 1.14.4 و Aether 2.4.0، از جمله WireGuard روی MASQUE و اتصال زنجیره‌ای اختیاری Psiphon اضافه شدند. دو پیش‌فرض با سایفون و بدون آن آماده‌اند. هویت دستگاه خصوصی دریافت می‌شود و آزمایش/یافتن endpoint پیشرفت و لغو دارد. دسترسی شبکه یا کشور خروجی تضمین نمی‌شود.
- بررسی گواهی و نام میزبان در HTTPS اتر فعال شده و هش فایل‌های اجرایی هنگام استفاده بررسی می‌شود. JSON اجازهٔ بازکردن listener عمومی، API کنترلی یا خواندن فایل‌های خصوصی محلی را ندارد.
- ترکیب پس‌زمینهٔ دارک غیر OLED در نبود محتوای پشت گلس اصلاح شد. پنجرهٔ دانلود آپدیت در Performance Mode پس‌زمینه و لبهٔ متمایزتری دارد.
- محدودیت مهم: برای اجرای JSON کامل Xray ابتدا اتصال فعلی را قطع کنید؛ هستهٔ فعلی اعتبارسنجی JSON بدون اجرا ندارد. پینگ مستقل JSON کامل و اتر با «اندازه‌گیری نشده» مشخص می‌شود. اندازه‌گیری ترافیک JSON کامل Xray همچنان ناقص است. رفتار لینک‌های معمولی قبلی حفظ شده است.

نسخهٔ **1.3.0**، بیلد پایهٔ **55** و کد نصب **4055**؛ اتر اندروید ۱۰ به بالا نیاز دارد. روی اپ با امضای قبلی نصب کنید و اپ یا اطلاعاتش را پاک نکنید. تغییرات سرور و my-sub جداگانه مستقر می‌شوند و APK آن‌ها را نصب نمی‌کند.
