## English

### niraNG 1.2.2 — routing fixes and floating navigation

Changes since the public 1.2.1 release, including its refreshed Performance APKs:

- Fixed Local DNS configuration generation: internal remote DNS queries explicitly use the proxy outbound, and unsupported DNS query types no longer take the legacy direct-forwarding path. The Local DNS/Sniffing/Route Only policy follows the working v2rayNG/PattNG configuration path. Route Only now follows its actual switch instead of being forced on by Iran bypass. This is a configuration-policy fix, not a guarantee that every network/server works or a complete DNS-leak audit.
- Added a real **Local network / localhost** routing selector: Automatic (historical direct local access), Bypass proxy, or Use proxy. Private addresses and local-name rules are controlled independently from Iran bypass, including local DNS handling. Through proxy, local addresses refer to the server's network and may be unreachable.
- New installations and explicit Settings Reset receive the revised network profile; updates do **not** overwrite existing user settings. Defaults include Iran bypass, Local DNS on, FakeDNS off, IPv6 on with IPv6 preference off, Sniffing on, Route Only off, and separate Direct DNS off. Google's DoH `/dns-query/` typo is normalized without rewriting arbitrary custom resolver paths or values.
- Changing local routing participates in the existing service-restart policy. Selecting another configuration remains immediate in the UI before core restart; the real VPN state and failure rollback remain service-controlled.
- Added floating, rounded bottom navigation with header-like ordinary translucency and Gaussian blur. Content continues behind the dock and Android's transparent system area where the OS supports it; Performance mode remains opaque and filter-free.
- Larger Clay-style Home/Servers/Settings icons have localized press depth and elastic drag. Dragging a navigation control does not activate its tap. Removed Material's duplicate grey touch halo around the icon. Transient confirmations use matching small Clay-style surfaces.
- Rounded touch highlights in settings choice dialogs now follow the option row instead of drawing a rectangular grey block. Dialog motion, choices and Apply/Cancel behavior are retained.
- Country flags anywhere in a configuration remark use clean bundled badges: the first flag occupies the main country slot, and additional flags stay inline. Stored names, IDs and subscription contents are unchanged.
- Telegram reminder history survives Settings Reset, so resetting preferences does not replay onboarding/reminder counts.
- Local shader preparation stays under the startup loading screen, with a bounded fallback. First-scene optical coordinates are primed once without waiting for a scroll/tap; there is no permanent repaint ticker. Background API checks remain separate from local initialization.
- Shared backdrop membership changes no longer repaint every existing member while sharing remains active. Only the transition into/out of sharing requests the required refresh; normal-mode full row lenses remain circular and live during scrolling.
- The Servers header action now reuses its optical host's computed glass via upstream vibrancy: its circular rim, specular highlight and interaction remain, without a second nested blur/refraction pass. Standalone three-dot controls and open popup menus keep premium optics. This reduces one known rendering cost; normal-mode Servers FPS on individual phones still needs device measurement and is not guaranteed at 120 FPS.
- Retained the previously published true matte Performance Mode, equal scroll momentum, outlined Connect button, guarded shader preparation when turning effects back on, correctly anchored fallback header menu, immediate configuration selection and smooth page motion.
- This version includes its own Persian/English release notes offline.

### APK choice and upgrading

- Version **1.2.2**, base build **24**, installation version code **4024 for all four APKs**. Same package and signing identity. Install over the existing 1.2.1/1.2.0/compatible older installation; do not uninstall or clear data. Automated tests cover existing settings and identity-preserving code paths; physical upgrades from every historical build have not been performed for this candidate.
- **arm64-v8a:** compatible 64-bit ARM Android phones; **armeabi-v7a:** compatible 32-bit ARM devices; **x86_64:** compatible x86-64 devices/emulators, not a universal phone APK.
- **Universal:** includes ARM64, ARM32 and x86-64 together; use it if unsure. It is larger, and still requires Android **7.0/API 24+** and a supported architecture.
- Windows, my-sub and server/PHP deployment are separate and are not installed by these APKs. No sing-box engine has been added.

## فارسی

### niraNG 1.2.2 — اصلاح روتینگ و نوار شناور

تغییرات نسبت به نسخهٔ عمومی 1.2.1، شامل APKهای اصلاح‌شدهٔ Performance همان انتشار:

- ساخت کانفیگ **Local DNS** اصلاح شد: درخواست‌های داخلی DNS راه دور صریحاً از پراکسی عبور می‌کنند و نوع‌های پشتیبانی‌نشدهٔ درخواست DNS دیگر از مسیر قدیمیِ ارسال مستقیم نمی‌روند. سیاست Local DNS، Sniffing و Route Only با مسیر کارکردهٔ v2rayNG/PattNG هماهنگ شد. Route Only واقعاً تابع سوییچ خودش است و حالت بای‌پس ایران آن را پنهانی روشن نمی‌کند. این اصلاح سیاست کانفیگ است؛ تضمین کارکرد همهٔ شبکه‌ها و سرورها یا تأیید کامل نبود نشت DNS نیست.
- گزینهٔ واقعی **شبکهٔ محلی / localhost** به Routing اضافه شد: خودکار با رفتار مستقیم قبلی، عبور مستقیم، یا عبور از پراکسی. قواعد IP خصوصی، نام محلی و DNS محلی مستقل از بای‌پس ایران کنترل می‌شوند. با پراکسی، آدرس محلی به شبکهٔ سرور اشاره می‌کند و ممکن است در دسترس نباشد.
- فقط نصب تازه یا **Reset تنظیمات** پروفایل پیشنهادی جدید را می‌گیرد؛ آپدیت تنظیمات فعلی کاربر را بازنویسی نمی‌کند. پیش‌فرض‌ها شامل بای‌پس ایران، Local DNS روشن، FakeDNS خاموش، IPv6 روشن با ترجیح IPv6 خاموش، Sniffing روشن، Route Only خاموش و Direct DNS جداگانه خاموش است. اشتباه `/dns-query/` در آدرس DoH گوگل اصلاح می‌شود؛ مسیر و مقدار DNS سفارشی دلخواه دست‌کاری نمی‌شود.
- تغییر حالت شبکهٔ محلی در سیاست ری‌استارت سرویس لحاظ شده است. انتخاب کانفیگ همچنان قبل از آماده‌شدن هسته در UI نمایش داده می‌شود؛ وضعیت واقعی VPN و برگشت انتخاب هنگام خطا را خود سرویس مدیریت می‌کند.
- نوار پایین شناور و گرد با ترنسپرنسی معمولی و بلور Gaussian شبیه هدر اضافه شد. محتوا پشت نوار شناور و بخش شفاف دکمه‌های خود اندروید ادامه دارد، تا جایی که سیستم‌عامل پشتیبانی کند؛ Performance همچنان مات و بدون فیلتر است.
- آیکن‌های بزرگ‌تر Home/Servers/Settings با طراحی Clay، عمق فشردن و کش‌آمدن محدود دارند. کشیدن آیکن، کلیک آن را فعال نمی‌کند. هالهٔ خاکستری تکراری Material حذف شد و پیام‌های موقت هم سطح کوچک هماهنگ با همین طراحی دارند.
- هالهٔ لمس گزینه‌های تنظیمات گرد شد و با فرم ردیف هماهنگ است؛ دیگر مستطیل خاکستری نمی‌کشد. حرکت دیالوگ و رفتار گزینه‌ها و Apply/Cancel حفظ شده‌اند.
- پرچم در هر جای نام کانفیگ به صورت تمیز نمایش داده می‌شود: اولین پرچم در جای اصلی کشور و پرچم‌های بعدی داخل متن. اسم ذخیره‌شده، شناسه و محتوای ساب تغییر نمی‌کند.
- سابقهٔ پیام‌های تلگرام با Reset تنظیمات حفظ می‌شود؛ ریست دیگر شمارندهٔ پیام‌های اولیه و یادآوری را از اول شروع نمی‌کند.
- آماده‌سازی محلی شیدر زیر لودینگ شروع اپ انجام می‌شود و مسیر جایگزین محدود دارد. مختصات گلس بعد از اولین صحنه یک بار آماده می‌شود، بدون نیاز به اسکرول یا لمس و بدون تایمر دائمی بازنقاشی. بررسی API پس‌زمینه همچنان از آماده‌سازی محلی جداست.
- تغییر تعداد اعضای گروه گلس تا وقتی اشتراک بلور فعال باقی می‌ماند، همهٔ اعضا را دوباره نقاشی نمی‌کند؛ فقط شروع یا پایان اشتراک بازنقاشی لازم را درخواست می‌کند. سه‌نقطه‌های حالت عادی دایره و زنده هنگام اسکرول باقی می‌مانند.
- دکمهٔ هدر Servers با مسیر vibrancy خود پکیج از گلس محاسبه‌شدهٔ هدر استفاده می‌کند؛ لبهٔ دایره، بازتاب و تعامل حفظ شده و بلور و شکست نورِ تودرتوی دوم حذف شده است. سه‌نقطه‌های مستقل و منوی باز گلس کامل دارند. یک هزینهٔ مشخص رندر کم شده؛ FPS حالت عادی سرورها هنوز روی هر گوشی نیاز به اندازه‌گیری دارد و ۱۲۰ فریم تضمین نمی‌شود.
- اصلاحات منتشرشدهٔ قبلی حفظ شده‌اند: Performance واقعاً مات، شتاب اسکرول یکسان، حاشیهٔ Connect، آماده‌سازی محافظت‌شدهٔ گلس هنگام خاموش‌کردن Performance، جای درست منوی جایگزین هدر، انتخاب فوری کانفیگ و حرکت نرم صفحه‌ها.
- توضیحات همین نسخه به فارسی و انگلیسی داخل APK و بدون اینترنت در دسترس‌اند.

### انتخاب APK و آپدیت

- نسخهٔ **1.2.2**، بیلد پایهٔ **24** و کد نصب **4024 برای هر چهار APK**؛ پکیج و امضای قبلی حفظ شده است. روی نصب فعلی 1.2.1/1.2.0/نسخهٔ قدیمی سازگار آپدیت کنید؛ اپ یا داده‌ها را پاک نکنید. مسیر حفظ تنظیمات و هویت تست خودکار دارد؛ آپدیت واقعی از تک‌تک بیلدهای تاریخی روی گوشی برای این خروجی انجام نشده است.
- **arm64-v8a:** گوشی با اندروید ARM شصت‌وچهاربیتی؛ **armeabi-v7a:** دستگاه ARM سی‌ودوبیتی؛ **x86_64:** دستگاه یا شبیه‌ساز x86-64، نه نسخهٔ همهٔ گوشی‌ها.
- **Universal:** هر سه معماری را دارد؛ اگر مطمئن نیستید این را انتخاب کنید. بزرگ‌تر است و همچنان اندروید **۷/API 24 به بالا** و معماری پشتیبانی‌شده می‌خواهد.
- ویندوز، my-sub و استقرار سرور/PHP جدا هستند و این APKها آن‌ها را نصب نمی‌کنند. هستهٔ sing-box اضافه نشده است.
