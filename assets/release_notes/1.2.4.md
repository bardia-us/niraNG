## English

### niraNG 1.2.4 — more connection options, simpler controls

Changes since **1.2.3**:

- Subscriptions can mix ordinary links, complete Xray/sing-box JSON and Aether presets. Full JSON retains its own routing and DNS instead of using the ordinary TLS editor. Added pinned sing-box 1.14.4 and Aether 2.4.0; the existing Xray core is retained.
- Added personal Aether profiles with MASQUE, WARP/WireGuard and WireGuard over MASQUE, optional Psiphon chaining, simple/advanced settings, endpoint discovery/manual checks and optional confirmed identity renewal. Failed renewal preserves the previous key. Psiphon has automatic selection and the official supported region catalog; a region selection does not guarantee an available exit.
- Servers has separate subscription/Aether groups with rounded Clay controls, lighter expansion, simultaneous scroll reveal and reorder boundaries. Psiphon country/brand indicators remain independent of profile names. Home uses the observed exit country for the connected Psiphon path.
- Fixed scrolling the Psiphon region list, Aether Save overlapping Android navigation, advanced-section animation/readability and the modern Psiphon icon edges. Saving changed connection settings restarts the edited active Aether profile; renaming or editing inactive profiles does not interrupt a connection. Pending connections/restarts can be cancelled.
- Fixed blocking native teardown and ownership races during VPN takeover/restart. Added independent real HTTPS latency measurements for full JSON and Aether with bounded resources and private temporary state. Cold Aether preparation can take longer than an ordinary ping. JSON/Aether real-delay results now use the same best-of-two, reusable-connection criterion as ordinary native probes.
- Added real full-Xray JSON usage accounting at the Android input boundary, avoiding duplicate counts from chained outbound helpers. Historic gaps remain marked as partial rather than being invented; ambiguous unsupported proxy re-entry is not added as exact usage.
- Fixed non-OLED dark background artifacts and improved Performance Mode download-dialog contrast, while preserving the established glass/Clay design. Existing peers/hostnames remain verified; no TLS checks were disabled.
- Companion my-sub updates add JSON name/remarks synchronization, reliable Cancel, first/last ordering, ordinary-link output for older Android/Windows clients and separate full-Xray exports for compatible iOS clients. These server files require their own deployment.

Version **1.2.4**, base build **58**, installation version code **4058**. Internal 1.3.0/1.3.1 test builds preceded this corrected public sequence; the installation code still increases. Android **7/API24+**; Aether needs **Android10+**. Install over the existing signed app without clearing data. Historic traffic gaps cannot be reconstructed; reachability, fixed exits and 120 FPS are not guaranteed.

## فارسی

### niraNG 1.2.4 — مسیرهای اتصال بیشتر، کنترل‌های ساده‌تر

تغییرات نسبت به **1.2.3**:

- اشتراک می‌تواند لینک معمولی، JSON کامل Xray و sing-box و پروفایل اتر را کنار هم داشته باشد. JSON کامل DNS و مسیریابی خودش را دارد و از ویرایشگر معمولی TLS پیروی نمی‌کند. هسته‌های sing-box 1.14.4 و Aether 2.4.0 اضافه شدند؛ نسخهٔ Xray قبلی حفظ شده است.
- ساخت اتر شخصی با MASQUE، وارپ/WireGuard و WireGuard روی MASQUE، زنجیرهٔ اختیاری سایفون، تنظیمات ساده/پیشرفته، جست‌وجو و بررسی دستی endpoint و تعویض اختیاری کلید با تأیید اضافه شد. تعویض ناموفق کلید قبلی را حذف نمی‌کند. سایفون انتخاب خودکار و فهرست رسمی مناطق قابل انتخاب دارد؛ کشور انتخابی لزوماً خروجی فعال ندارد.
- سرورها به دو بخش اشتراک و اتر با کنترل‌های گرد Clay، بازشدن سبک‌تر، اسکرول هم‌زمان و مرز جابه‌جایی تقسیم شدند. پرچم و نشان سایفون به نام دلخواه پروفایل وابسته نیستند. Home کشور خروجیِ مشاهده‌شدهٔ اتصال سایفون را نمایش می‌دهد.
- اسکرول لیست کشورها، رفتن Save زیر نوار گوشی، انیمیشن و خوانایی بخش پیشرفته و لبه‌های آیکن جدید سایفون اصلاح شدند. ذخیرهٔ تنظیمات اتصالِ اتر فعال، همان اتصال را راه‌اندازی مجدد می‌کند؛ تغییر نام یا ویرایش پروفایل غیرفعال اتصال را قطع نمی‌کند. اتصال و ری‌استارتِ در حال انجام قابل لغو هستند.
- مسیر توقف هسته و تداخل عملیات قدیمی با اتصال جدید اصلاح شد. پینگ واقعی HTTPS مستقل برای JSON کامل و اتر با منابع محدود و فایل‌های موقت جدا اضافه شد؛ آماده‌سازی اولیهٔ اتر می‌تواند طولانی‌تر از پینگ معمولی باشد. معیار پینگ JSON/اتر با پینگ معمولی هماهنگ شد: کمترین زمانِ دو درخواست واقعی با امکان استفادهٔ دوباره از اتصال.
- ثبت واقعی مصرف JSON کامل Xray در مرز ورودی اندروید اضافه شد تا خروجی‌های زنجیره‌ای دوباره شمرده نشوند. فاصله‌های ثبت‌نشدهٔ قبلی همچنان ناقص مشخص می‌شوند؛ توپولوژی مبهمِ ورود مجدد در حالت پروکسی به‌عنوان مصرف دقیق جمع زده نمی‌شود.
- اشکال پس‌زمینهٔ دارک غیر OLED و تمایز پنجرهٔ دانلود در Performance Mode بهتر شد و طراحی گلس/Clay حفظ شده است. بررسی گواهی و نام میزبان فعال است و هیچ کنترل TLS خاموش نشده.
- اصلاحات جداگانهٔ my-sub شامل هماهنگی نام و remarks، لغو درست فرم JSON، انتقال به اول/آخر، خروجی لینک‌های معمولی برای کلاینت‌های قدیمی اندروید/ویندوز و خروجی مجزای Xray کامل برای کلاینت مناسب آیفون است. فایل‌های سرور جداگانه آپلود می‌شوند.

نسخهٔ **1.2.4**، بیلد پایهٔ **58** و کد نصب **4058**. نام نسخه‌های آزمایشی داخلی 1.3.0 و 1.3.1 به روند عمومی درست برگشته؛ کد نصب همچنان افزایشی است. اندروید **۷/API24 به بالا**؛ اتر **اندروید۱۰ به بالا** نیاز دارد. روی نسخهٔ هم‌امضا نصب کنید و داده‌ها را پاک نکنید. مصرفی که قبلاً ثبت نشده قابل بازسازی نیست؛ دسترسی، خروجی ثابت و ۱۲۰ فریم تضمین نمی‌شود.
