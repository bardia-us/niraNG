## English

### niraNG 1.3.1 — multicore fixes and clearer Aether controls

- Fixed blocking native teardown during VPN takeover and disconnect, with ownership guards against stopping a newer connection.
- Added isolated real HTTPS latency probes for complete Xray/sing-box JSON and Aether profiles. Cold Aether preparation can take longer; a measurement is not a guarantee that every destination is reachable.
- Refined the subscription/Aether group bars, expansion and scroll animations, add control and drag boundaries. Removed redundant JSON and Aether indicators and the extra Aether information page.
- Aether settings now has the established frosted header, simpler sections, manual endpoint checks, the official supported Psiphon region catalog and optional confirmed identity renewal. A selected region is not guaranteed to be available. Existing keys survive failed renewal.
- Companion my-sub changes restore ordinary-link subscriptions for older Android/Windows clients, provide a separate full-Xray JSON feed for compatible iOS clients, and fix JSON Cancel, name/remarks synchronization and move-to-first/last. These server files require separate deployment.

Version **1.3.1**, base build **56**, Android version code **4056**. Install over the existing app; do not clear data. No core-version upgrade or Glass renderer replacement is included. Complete Xray JSON traffic accounting remains partial.

## فارسی

### niraNG 1.3.1 — رفع باگ هسته‌ها و تنظیمات مرتب‌تر اتر

- گیرکردن مسیر قطع اتصال و واگذاری VPN به اپ دیگر اصلاح شد؛ عملیات قدیمی نباید اتصال جدیدتر را متوقف کند.
- پینگ واقعی HTTPS برای JSON کامل Xray و sing-box و اتر، با اجرای مستقل و موقت اضافه شد. آماده‌سازی اولیهٔ اتر ممکن است بیشتر طول بکشد؛ پینگ موفق تضمین دسترسی به همهٔ مقصدها نیست.
- نوارهای اشتراک و اتر، انیمیشن بازشدن و اسکرول هم‌زمان، دکمهٔ افزودن و مرز جابه‌جایی مرتب شدند. نشان اضافی JSON و صفحهٔ اطلاعات تکراری اتر حذف شد.
- هدر شفاف استاندارد، بخش‌بندی ساده‌تر، بررسی دستی endpoint، فهرست رسمی مناطق قابل انتخاب سایفون و تعویض اختیاری کلید با تأیید اضافه شد. کشور انتخابی لزوماً در دسترس نیست؛ تعویض ناموفق کلید سالم قبلی را حذف نمی‌کند.
- اصلاحات جداگانهٔ my-sub شامل خروجی لینک‌های عادی برای نیراهای قدیمی و ویندوز، خروجی مجزای JSON کامل Xray برای کلاینت مناسب آیفون، رفع لغو فرم JSON، هماهنگی نام و remarks و انتقال به اول/آخر است. فایل‌های هاست باید جداگانه جایگزین شوند.

نسخهٔ **1.3.1**، بیلد پایهٔ **56** و کد نصب **4056**. روی نسخهٔ قبلی نصب کنید و داده‌ها را پاک نکنید. نسخهٔ هسته‌ها و رندر گلس عوض نشده‌اند. شمارش ترافیک JSON کامل Xray همچنان ناقص است.
