# Frozen Iran CIDR sources

The runtime files in this directory are plain CIDR snapshots. niraNG never
downloads routing data while starting or connecting.

- Source project: Chocolate4U/Iran-v2ray-rules (primary data/reference)
- Plain-CIDR companion source: Chocolate4U/Iran-clash-rules
- Frozen source file: `release/ircidr.txt`
- Frozen commit: `9f9b81801e15177930073faa279010f0c6c0f281`
- Frozen on: 2026-08-26

`iran_ipv4.txt` and `iran_ipv6.txt` are produced by removing comments and
splitting the upstream list by address family. Keep the upstream licenses and
attribution in mind when refreshing these snapshots.
