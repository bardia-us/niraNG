## English

### niraNG 1.2.3 — clearer glass, smoother interaction and connection settings

Changes since the public 1.2.2 release:

- Refined optical glass in light and dark themes with a clear refractive material, more restrained header highlights and tighter continuity between the lens and its thin rim.
- Reduced repeated backdrop captures and rendering work while scrolling Servers. Home surfaces and server action dots use lighter decorative depth; compatible header/navigation blur inputs share work. Scrolling improved on the measured device; 120 FPS is not guaranteed.
- Refined elastic drag, stretch and press motion. Server action controls stay attached during card presses and reordering; the entire held card and its control now stay above neighboring row controls. Text-heavy dialogs have more readable backdrops, consistent Clay Apply/Cancel actions and smoother menu transitions. Performance Mode keeps opaque, filter-free surfaces.
- Added compact measured traffic totals for today and the current Gregorian month to Home. These count core upload + download across configurations, exclude transport overhead and differ from provider quota usage. `≥` marks partial accounting; there is no per-profile breakdown or speed meter.
- Fixed TLS certificate-pin forwarding: `pcs` and `pinSHA256` normalize to Xray's SHA-256 certificate-pin string. Verification names are forwarded as names; malformed or conflicting certificate constraints are rejected instead of silently dropped.
- Fixed TCP HTTP header generation: Host and Path values now reach Xray's request settings with the required request defaults. Existing VLESS encryption forwarding is retained.
- Extended CDN/TLS profile editing with ECH configuration and an optional ECH outbound JSON helper. The helper routes ECH resolver requests through Xray's `echSockopt.dialerProxy`; invalid or recursive helpers are rejected, and entered JSON formatting is preserved. Real connection success still depends on the server and network.
- A successful subscription refresh now restores source profiles and clears manual profile overrides, including ECH edits. Failed refreshes preserve the existing subscription and edits.
- Update-download failures now show retry, browser-download and alternate-network guidance. Browser recovery stays on the official release/download destination, and failed downloads no longer look as though they are still progressing.
- Adjusted Android task handling to reuse the app's task, kept profile Save above system navigation and the keyboard, and refreshed ping/IP results without requiring a scroll. The VPN Quick Settings tile shortcut is now under General; the Advanced battery-optimization entry was removed.

### APK choice and upgrading

- Version **1.2.3**, base build **54**, installation version code **4054 for all four APKs**. Same package and signing identity; install over a compatible existing niraNG installation without uninstalling or clearing data. Upgrades from every historical build have not been physically tested.
- **arm64-v8a:** 64-bit ARM Android; **armeabi-v7a:** 32-bit ARM Android; **x86_64:** compatible x86-64 devices/emulators.
- **Universal:** includes all three architectures; choose it if unsure. Every APK requires Android **7.0/API 24+** and a supported architecture.
- This is an Android release. Windows and server/PHP deployment are separate. These notes are also available offline inside the app.

## فارسی

### niraNG 1.2.3 — گلس شفاف‌تر، تعامل روان‌تر و تنظیمات اتصال

تغییرات نسبت به نسخهٔ عمومی 1.2.2:

- گلس اپتیکال در تم روشن و تیره با متریال شفاف و شکست نور بازتنظیم شد؛ بازتاب هدر ملایم‌تر و پیوستگی تصویر لنز با لبهٔ باریک آن بهتر شده است.
- تصویرگیری تکراری از پس‌زمینه و کار رندر هنگام اسکرول Servers کمتر شد. سطوح Home و سه‌نقطه‌های سرورها عمق تزئینی سبک‌تری دارند و ورودی‌های سازگار بلور هدر و نوار پایین مشترک شده‌اند. اسکرول روی دستگاه اندازه‌گیری‌شده بهتر شده؛ ۱۲۰ فریم تضمین نمی‌شود.
- حرکت کشسانِ کشیدن، کش‌آمدن و فشردن بازتنظیم شد؛ کنترل‌های هر سرور هنگام فشردن کارت و جابه‌جایی همراه آن می‌مانند و کل کارتِ نگه‌داشته‌شده با سه‌نقطه‌اش بالاتر از کنترل‌های ردیف‌های دیگر قرار می‌گیرد. پنجره‌های متنی پس‌زمینهٔ خواناتر، دکمه‌های Apply/Cancel هماهنگ با Clay و حرکت منوی روان‌تری دارند. سطوح Performance مات و بدون فیلتر باقی مانده‌اند.
- جمع ترافیک اندازه‌گیری‌شدهٔ امروز و ماه میلادی جاری به Home اضافه شد. اعداد مجموع ارسال و دریافت هسته در همهٔ کانفیگ‌ها هستند، سربار انتقال را ندارند و با مصرف ثبت‌شدهٔ سرویس‌دهنده فرق دارند. `≥` یعنی اندازه‌گیری ناقص؛ ریزمصرف هر کانفیگ یا سرعت‌سنج ارائه نمی‌شود.
- انتقال pin گواهی TLS اصلاح شد: `pcs` و `pinSHA256` به رشتهٔ SHA-256 موردنیاز Xray تبدیل می‌شوند. نام‌های بررسی گواهی هم به‌صورت نام منتقل می‌شوند؛ محدودیت‌های نامعتبر یا متناقض گواهی رد می‌شوند و بی‌صدا کنار گذاشته نمی‌شوند.
- ساخت هدر TCP HTTP اصلاح شد؛ Host و Path همراه با پیش‌فرض‌های لازم به تنظیمات درخواست Xray می‌رسند. انتقال قبلی VLESS encryption حفظ شده است.
- ویرایشگر CDN/TLS اکنون تنظیم ECH و JSON اختیاری ECH outbound را دارد. این خروجی کمکی، درخواست resolver مربوط به ECH را از `echSockopt.dialerProxy` در Xray عبور می‌دهد؛ مقدار نامعتبر یا حلقه‌ای رد می‌شود و قالب‌بندی JSON واردشده حفظ می‌شود. موفقیت اتصال واقعی همچنان به سرور و شبکه بستگی دارد.
- آپدیت موفق اشتراک، پروفایل اصلی منبع را برمی‌گرداند و تغییرات دستی پروفایل، از جمله ECH، را پاک می‌کند. آپدیت ناموفق، اشتراک و ویرایش‌های موجود را حفظ می‌کند.
- پس از شکست دانلود آپدیت، راهنمای تلاش دوباره، دانلود با مرورگر و امتحان شبکهٔ دیگر نمایش داده می‌شود. مسیر مرورگر به انتشار یا دانلود رسمی محدود است و دانلود ناموفق دیگر شبیه دانلود در حال پیشرفت نمایش داده نمی‌شود.
- مدیریت task اندروید برای استفادهٔ دوباره از task اپ تنظیم شد؛ Save پروفایل بالای نوار سیستم و کیبورد می‌ماند و نتیجهٔ پینگ/IP بدون نیاز به اسکرول تازه می‌شود. میان‌بر VPN در Quick Settings به General منتقل و گزینهٔ Battery optimization از Advanced حذف شد.

### انتخاب APK و آپدیت

- نسخهٔ **1.2.3**، بیلد پایهٔ **54** و کد نصب **4054 برای هر چهار APK**؛ پکیج و امضای قبلی حفظ شده است. روی نصب قبلیِ سازگار niraNG آپدیت کنید و اپ یا داده‌ها را پاک نکنید. آپدیت واقعی از تک‌تک بیلدهای تاریخی آزمایش نشده است.
- **arm64-v8a:** اندروید ARM شصت‌وچهاربیتی؛ **armeabi-v7a:** اندروید ARM سی‌ودوبیتی؛ **x86_64:** دستگاه یا شبیه‌ساز سازگار x86-64.
- **Universal:** هر سه معماری را دارد؛ اگر مطمئن نیستید این را انتخاب کنید. همهٔ APKها اندروید **۷/API 24 به بالا** و معماری پشتیبانی‌شده می‌خواهند.
- این انتشار مخصوص اندروید است؛ ویندوز و استقرار سرور/PHP جدا هستند. همین توضیحات داخل اپ و بدون اینترنت هم در دسترس‌اند.
